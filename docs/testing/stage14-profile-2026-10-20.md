# Ordinary dedicated before/after, 2026-10-19/20

Baseline: frozen source после08, до09; after: итоговый рабочий пакет08–14. Исторический Oct11 не используется. Manifest обеих исходных сборок приложен; common profile source и environment проверены сравнением.

CPU Intel Core i5-10300H @2.50GHz,4 cores/8 threads,RAM15.87GiB; Java17.0.19+10, -Xms1G/-Xmx4G, JFR profile. Seed8675309, standalone pinned modlist; Forge47.4.20/TaCZ1.1.8-hotfix2/SimpleBedrockModel2.2.2 bundled runtime. Конфиги/оружие/fixture одинаковы, отдельные JVM и миры. Фоновая нагрузка Windows не контролировалась, JIT/host noise остаётся ограничением.

Общий native warmup280ticks, затем80ticks перед каждой фазой; по2 повтора. Каждый обычный sample120ticks, dynamic200, unload500; soak2400 (120s) дважды. AK47 FINITE magazine30+chamber1/reserve120, для soak reserve100000. Ровно N активных NPC, NPC-only1 без противника.

Границы измерений: tickTimes — native Minecraft tick до Forge END callbacks, TPS — реальный sampled interval. Goal, nested native safety/hearing и adapter maintenance пересекаются и не суммируются как server cost. Before неизвестные component counters=-1/NOT AVAILABLE (в ns→ms также отрицательные), не нули. worldQueries считает только наши фактические adapter calls, queries — разрешения/list pages, не весь vanilla/TaCZ.

Wall-open→first native projectile и visual episode sample→projectile посчитаны отдельно в ticks; reacquire — новая видимая episode. Эти данные не являются human reaction latency. В non-wall сценах owner count включает warmup, поэтому performance credit для них запрещён; actual measured rounds warmup исключает. Ранний замер с дырявой стеной отменён и не входит в таблицу.

JFR CPU/allocations — sampling estimates с исключением startup/warmup/teardown. Ноль samples категории означает отсутствие sample, не нулевую стоимость. Top stacks/classes, allocations по scope/фазе и coverage приложены; fixture отделена от native/hearing/projectile physics.
