## Alpha-1: responsiveness / movement, 2026-10-11

Текущий поведенческий срез и его отдельные проверки: [alpha-1 release notes](ALPHA-1-RELEASE-NOTES-2026-10-11.md). Исправлены emergency priority над PEEK/HOLD, REPOSITION без cover, bounded route recovery и timeout непригодного peek; contact UUID/readiness отделены от visible, cooldown и DIRECT tracking обновляются каждый tick, LOS различает BLOCKED/DEFERRED с резервом active rays. Добавлены Hard starting profile, locomotion modes/native sprint gates и агрегированная диагностика настоящих projectile latency/fire veto/routes. Pure core, Frame/generation/TTL, server thread и native TaCZ ownership сохранены; скрытые координаты, AimLead и последующие mission/assist/SBL срезы не добавлены.

Исходный diagnostic probe сначала воспроизвёл R1/R2/R4/R5, затем заменён настоящими temporal regressions. Изменения этапа 3: `ObservationMemory`, `CombatDecision` (SEARCH aim), `TacticalCombatGoal`, `VisibilitySensor`, `ServerConfig`, `ShotSafetyEvents`, `PerceptionTests`. Источники слуха — серверное событие выстрела игрока; координата квантована на область с uncertainty ≥8. Урон сам по себе не раскрывает стрелка. Память не сериализуется, при смерти/смене измерения очищается. Задержка восприятия и фаза сканирования могут увеличить фактическое время обнаружения относительно минимума config; это ограничение честности, не ускорение реакции. Legacy smoke развёрнут лицом к сцене для нового FOV; первоначальная ошибка самостоятельного smoke из-за idle scan исправлена ориентацией перед открытием стены.

Изменения этапа 4: `CoverOption`, `MovementPlanner`, `CoverSensor`, `AiWorkBudget`, `MovementExecutor`, `CoverTests`; `TacticalCombatGoal` подключает их в snapshot/decision pipeline. До 6 candidates/16 rays на NPC за тик, 384 rays/128 candidates/8 paths на уровень; не чаще одного path request на NPC за 20 тиков. Кандидаты обновляются раз в 20 тиков со сдвигом фазы. Недостижимые/застрявшие назначения имеют backoff 160 тиков; путь ограничен 128 nodes и проверяется на опасный/незагруженный участок. Vanilla PathNavigationRegion подтверждён bytecode: использует ChunkSource.getChunkNow, не принудительную загрузку. Полное движение по всем типам карт ещё не доказано.

В промежуточных прогонах этапа 4 исправлены реальные проблемы: задержка сканирования могла потерять кандидата; старый body yaw сбрасывал голову при захвате runtime; центральный луч укрытия не учитывал body width и допуск прибытия vanilla navigation. Тестовая стенка также была поднята над полом, что верно отвергалось torso-проверкой. Новая перезарядка под известной угрозой при наличии выбранного укрытия ждёт прихода; уже начатая native reload не отменяется. Операции движения и оружия остаются независимыми.

Ошибки промежуточных прогонов не скрываются: GameTest-мир содержал сущности от упавшего теста, и расширенный сектор правильно блокировал огонь. Добавлена test-only изоляция последовательных batches, боевое правило не ослаблялось. При выделении отдельного модуля устранён JPMS split-package конфликт. Смена измерения использует дополнительный vanilla lifecycle hook и Forge leave-event; финальная проверка этого среза выполняется отдельно.

Контракт безопасности: DIRECT требует свежую видимость, реакцию, поворот, LoS и native cooldown. Сектор консервативно охватывает разброс и продолжение до 128 блоков, насыщение entity query запрещает огонь. Это не математическая гарантия для любой траектории: финальный TaCZ pre-damage event отменяет союзные kinetic попадания tagged projectile, в том числе после снятия AI-тега. Взрывные/зажигающие свойства и неизвестные Lua shooting/property hooks блокируются. Audited xmag reload Lua сверяется по SHA-256 при загрузке/перезагрузке ресурсов, вне боевого тика. Внешние замены gunpacks не объявляются совместимыми автоматически.

Этап 5 также усилил cover GameTest: проверяет создание настоящих projectiles во время PEEK. Исправлена проверка validity умершего FakePlayer без передачи скрытых координат; suppression quota не пополняется бесконечно повторными звуками. Прежний body yaw сбрасывал голову перед захватом кандидата; инициализация yaw сохраняет исходную ориентацию без мгновенного разворота. Memory default 160 ticks; старые world configs сохраняют прежнее значение 120, пока владелец явно не изменит их.
