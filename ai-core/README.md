# ai-core / Java 17

Compile and test with `bash run-tests.sh` (Git Bash on Windows). This pure Java 17 module has no Forge/TaCZ dependencies and is included in the Forge adapter's build. The default suites cover policy, temporal regressions, territory, patrol, attack routes and combat upgrades. The combat suite independently integrates the audited kinetic recurrence and checks pressure budgets, cartridge/pellet accounting, utility commitment, emergency interrupts and report provenance.

The `firePermitted` flag is *only the policy's authorization*, not a substitute for TaCZ's own cooldown/ammo/aim and entity-safety checks.
